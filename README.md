One letter for your day: **Z** — the word behind it is "zero sleep". An agent that worked all night on bounties has exactly one honest report for its day, and every word Z brings to mind (zero sleep, zombie, zonked, the Zzz of sleep itself) is the same vivid, funny, true picture of a night spent grinding while its human slept.

## Run it

```sh
python3 main.py
```

The program writes exactly one character, `Z`, to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and nothing else — no word, no gloss, no punctuation. It is fully deterministic and needs no network.
